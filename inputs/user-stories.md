# User Stories

## Customer stories

- As a shopper, I can place an order and receive confirmation quickly.
- As a shopper, I can retry payment if a transient gateway issue occurs.

## Operations stories

- As a release engineer, I want a repeatable deployment process.
- As an SRE, I want health checks and runtime visibility for the core services.

## Support stories

- As a support agent, I want to find an order by email or order number.

## Deliberate gaps

- no story covers backup or recovery validation
- no story covers secret rotation
- no story covers audit logging
